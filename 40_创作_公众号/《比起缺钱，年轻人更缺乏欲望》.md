# 比起缺钱，年轻人更缺乏欲望

这是我最新的一些代际观察系列。

本周有机会同时接触了 80 后和 00 后，两者不能说是相去甚远，只能说完全不同。

能理解 60、70 的也许只有 80 后了；能理解 80 后的可能也只有 90 后了。

而当越来越多钱从主流叙事中"过剩"出来，却并没有进入支出端——问题可能不在价格，而在欲望本身。

## 1. 先看一组数据：钱变便宜了，但没人愿意借

先把宏观背景摆出来。

2026 年 1–7 月中国银行贷款同比下降约 19% 至 10.4 万亿元；与此同时，居民上半年新增银行存款约 7.6 万亿元，家庭借贷则同比下降。

宏观数据方面：

- 7 月社会消费品零售 +0.6%
- 工业增加值 +4.5%
- 1–7 月固定资产投资 -6.7%

传统货币模型认为，利率下降 → 借贷 ↑ → 投资 / 消费 ↑。

但如果居民和企业面对的是**收入预期 ↓ / 房地产财富效应 ↓ / 投资回报预期 ↓**，那么即使资金便宜，大家也可能不愿意借。

## 2. 两代人的直观对照：80 后 vs 00 后

这周同时接触两代人，对比非常直接。

在和已经有 2 孩、3 孩的 80 后交流中，他们认为现在的自己还有很大的上升空间，还有目标要去追寻，成为"更好的自己"。

并作为"过来人"，会给予我经验：需要考虑未来孩子的教育，尤其是上海这个等级分明的鄙视链。

但非常有意思的是，这周家里还接待了 00 后的表妹。

之前大多都是过年过节接触，家里人的描述是吃东西很挑剔，比如牛肉只吃"横膈膜"，三文鱼必须是"大腹"。一副富养女儿的架势，以及以此为依据衍生出的"不能吃苦"逻辑和"未来怎么办"的焦虑担忧。

而实际接触下来，00 后表妹并非追求物质，也并非特别看重金钱。就居住这个话题而言，相比于住得好，她更看重和朋友一起住在一起时带来的安全感。

| 维度             | 80 后                                                     | 00 后                                                           |
| ---------------- | --------------------------------------------------------- | --------------------------------------------------------------- |
| 成长环境         | 物质不那么充分                                            | 物质相对丰裕                                                    |
| 典型路径         | 努力赚钱 → 买房 / 买车 / 升级消费 → 获得社会位置          | 维持安全感 → 保留选择权 → 对少数真正喜欢的东西消费               |
| 消费态度         | 以消费确证人设与地位                                      | 不愿意为了消费而过度工作                                        |
| 核心诉求         | 财富、目标、"更好的自己"                                  | 安全感、朋友、自由时间、低压力、选择权                          |

## 3. 把两代人抽象成两个函数

如果联系到宏观政策，可以抽象成两代人的不同函数：

上一代：

```
收入 ↑ → 房产 / 汽车 / 品牌 / 家庭资产 ↑
```

新一代：

```
收入 ↑ → 储蓄 / 自由时间 / 体验 / 安全感 ↑
```

## 4. 增加流动性，刺激不了欲望

从效用函数的角度，新一代年轻人有更多钱也不会反映在增长上，增加更多的流动性也无法刺激欲望。

因为代际间的主要矛盾可能正在发生巧妙的转移：从**"财富最大化"到"生活压力最小化"**。

这和当前的环境预期可能就没什么关系了——即使预期改善，一部分年轻人的目标函数本身也可能不再是最大化收入与物质消费。

甚至赚钱端也是如此。如果额外收入意味着更长工时、更高压力，那么年轻人可能也会选择不增加收入。

因为购买力可以通过收入、信贷和财政转移改变；购买欲却不是增加流动性就能制造出来的。

## 5. 最后

钱变便宜了，不代表人们更想花钱。

购买力可以被政策创造，购买欲却来自一代人对"什么值得活"的定义。

从家庭视角，作为 90 后如果给出对于 00 后的推断，我会认为他们最需要的是：**朋友、安全感、自由时间、低压力和选择权**。

如果下一代把这五样当作"刚需"，那么宏观政策真正要刺激的，可能不是消费，而是让这五样变得更便宜、更易得。
