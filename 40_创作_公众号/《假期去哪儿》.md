# 假期去哪儿：我把端午旅行决策交给了 DeepSeek

## 01｜想忘掉设备 3 天

我突然发现我，以及很多城市人的 1 天都是围绕四块屏幕展开，手机、平板、电视、电脑，精准的覆盖了你的碎片化时间、白天工作、晚上娱乐的全部时间。

有点厌倦了，想忘掉设备 3 天；

冲！

决定还是要粗门，

不一样的是，这一次我选择让渡主观给 agent，DeepSeek 帮我做了端午旅行的决策。

（此时距离放假只有 2 天，临时选择目的地和买车票总是会艰难一些）

通勤的地铁上，我开始了和 DeepSeek 的对话；

## 02｜第一次推荐：冷门目的地

第一个 Prompt，

我问他：“

端午节国国内有哪些相对冷门的？地方可以玩，评价指标是当地的酒店涨幅，还有飞机票价格并没有较平日有明显提升。

”

他推荐了

湖北秭归：端午文化发源地、

广西靖西：中越边境“小桂林”、

浙江松阳：“江南最后的秘境”

接着我再携程上搜了这些目的地的住宿价格；发现，不对，这些地方端午价格暴涨啊！

## 03｜加入价格约束

于是反问：“

你认为高于日均涨幅 50% 算是变贵吗？

”

于是得到了回答：

是的，高于日均涨幅 50% 绝对算“明显变贵”，在旅游行业这已属于显著的价格信号。

更进一步，告诉他，我具体出发城市是上海，预算不限。但不能当冤大头，必须限制涨幅在 20% 以内；

于是获得了进一步的推荐：

贵州镇远县、

湖北鹤峰县、

福建霞浦县、

山西浑源县、

江西瑶里古镇。

## 04｜瑶里古镇浮出水面

搜索了一圈，突然发现，

江西瑶里古镇的涨幅竟然只有 20.24%

DeepSeek 也投来了赞赏的目光：“

在端午假期，这个涨幅甚至算得上“捡漏”了。这也印证了我之前说的——

瑶里古镇属于“非景区溢价区”，价格确实稳。

不过，绝对值上差价是 200 元。考虑到你“预算不限”，这多出的钱相比在人山人海的市区挤高价酒店，换来古镇里推窗见景的清净体验，性价比其实很高。

”

嚯，这一顿吹捧，把我看的爽死；

这下是捡到宝了。

进一步的，让他帮我推荐了古镇的酒店。于是，发现了断层领先的“景德镇弗居人文民宿”。

然后是交通方式的推荐，DeepSeek 明确了当地的租车方案更划算；

“高铁+当地租车”这个方案非常可行，甚至可以说是前往瑶里古镇体验感和自由度兼顾的最佳选择，完美契合你“预算不限、追求体验”的需求。

（后来发现事实也是如此）

第四个 Prompt 是：

帮我总结一下当前的旅行成本。

第五个是：

写一个简版的出行方案。方便通知同伴。

和三爪沟通后，我开始了这趟盲盒之旅。

## 05｜打开盲盒

出发前一天，看了天气预报，三天都有大雨；不过考虑都已经订好了行程，也只能随遇而安了。

到达目的地后，打开了盲盒，真是一个大赞；

这次旅行后，又获得了一个重要的线索，就是“黑松露度假指南”。

避开人群，获得一个小众避世感的宝藏度假地；

## 06｜一个好 Prompt 的价值

一个足够有效的 Prompt 就可以让 DeepSeek 大量翻阅最新的内容网页，然后给出足够有效的信息反馈。

绝大多数人其实并不需要那么多新的 AI 应用；而是用好已有的成熟工具。

很多所谓「AI 应用」其实是在重复造 ChatGPT / DeepSeek 已经做得很好的东西：搜索、总结、推理、生成、对比。

真正有价值的不是再做一个弱版 Agent，而是做一个让现有 Agent 更好用的输入层。

这个「假期去哪儿」就是典型例子：

不需要自己做旅行推荐系统。

只需要把用户输入、候选池、判断标准、输出格式，组织成一个高质量 Prompt，让 ChatGPT / DeepSeek 去完成搜索和判断。
